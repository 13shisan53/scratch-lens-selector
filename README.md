# 划痕检测 · 工业相机与镜头选型助手

单文件网页工具，用于为**划痕缺陷检测**场景挑选合适的工业相机与镜头，目标精度可到 **0.1 mm**。
无需安装、无需联网，双击 `划痕检测镜头选型助手.html` 用浏览器打开即可使用。

## 功能

输入检测需求，自动完成：

1. **像素当量计算**：最小划痕 ÷ 要求像素数 → 物面像素当量（mm/px）
2. **相机筛选**：由「视野 ÷ 像素当量」得到所需分辨率，联合视野约束筛出可行相机并打分
3. **镜头计算**：放大倍率 β = min(传感器宽÷视野宽, 传感器高÷视野高)，理想焦距 f ≈ WD·β/(1+β)，薄透镜物距 u = f(1+1/β)、像距 v = f(1+β)，自动判断是否需要接圈
4. **光学校核**：镜头分辨率需求 1/(2·划痕·β)、图像圈是否覆盖靶面、景深 DOF = 2·N·c·(1+β)/β²、衍射斑 2.44·λ·N
5. **推荐结果**：相机 + 镜头组合、候选对比表、光路示意图、计算明细、按材质给出的打光方案

## 输入参数

| 参数 | 含义 | 影响 |
|---|---|---|
| 最小可检测划痕 | 要可靠发现的划痕宽度 (mm) | 最敏感参数，减半 → 所需像素数 ×4 |
| 检测视野 FOV 宽/高 | 单次拍摄覆盖的物面范围 (mm) | 与精度共同决定相机像素数 |
| 每划痕像素数 | 2 / 3 / 5 px | 2=奈奎斯特极限，3=工程值，5=适合 AI 分类 |
| 工作距离上下限 | 镜头前端到物面的机械空间 (mm) | 决定选多长焦距 |
| 面差 / 倾斜 | 被测面高低落差 (mm) | 与景深比对 |
| 表面材质 | 金属 / 塑料 / 玻璃 / 橡胶 | 决定照明方案建议 |
| 优先低畸变 | 打分权重 | 勾选后畸变 ≤0.1% 的镜头加分 |
| 需要双远心 | 切换镜头族 | 固定倍率远心，标准镜头降权 |

## 使用建议

- 打光是划痕检测成败的关键：金属件用**低角度暗场**（背景暗、划痕亮），玻璃镜面用**同轴光**（背景亮、划痕暗）。
- 光圈建议工作在 **F4~F8**：收到 F11 后衍射斑超过像元尺寸，细小划痕会糊。
- 量产前务必用真实样品 + 标定板实拍验证（工具内含「落地验证清单」）。
- 若要测划痕长度或位置，请使用低畸变 / 双远心镜头并做畸变校正。

## 自定义相机与镜头库

文件 `<script>` 中有三个数组，直接按同样格式增删即可，刷新页面生效：

- `CAMERAS`：`{name, res:[宽,高]像素, px:像元μm, grade:成本档}`
- `LENSES`：`{name, f:焦距mm, ic:图像圈mm, lp:分辨率lp/mm, fnum:最大光圈, dist:畸变%, mwd:最近物距mm, price:价位, type:'std', macro:true}`
- `TELECENTRIC`：`{name, mag:固定倍率, fov:物方最大视野mm, wd:固定工作距离mm, lp, price, type:'tele'}`

图像圈参考：2/3" = 11 mm，1" = 16 mm，1.1" = 17.6 mm，4/3" = 22.5 mm。
